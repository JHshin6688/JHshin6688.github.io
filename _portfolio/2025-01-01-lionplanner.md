- Built a full-stack web app that helps Columbia students plan course schedules and evaluate semester workload
- Developed a data pipeline that scrapes course syllabi and reviews with Firecrawl, uses parallel LLM chains to analyze workload across multiple aspects, and stores results in Supabase
- Implemented an agentic workflow with LangGraph, combining an LLM router and a tool-calling RAG agent for course recommendations and schedule-grounded workload analysis
