summary: "At HackTX 2024, my team addressed the web accessibility challenge faced by blind and low-vision users who struggle with navigating text-heavy web content. To solve this, we built a Chrome extension that generates context-aware audio summaries for click-to-listen navigation. As part of a four-person team, I worked on the backend development by implementing the web content summarization pipeline using LangChain Mistral AI, which extracts raw page content and transforms it into concise, text-to-speech-ready audio summaries. Through this implementation, we successfully improved web navigation for visually impaired users and were awarded the Best AI Project with Databricks Open Source."
