summary: "To address the difficulty Columbia students face in assessing course workload and planning balanced semester schedules, I developed a full-stack web application for automated workload analysis and personalized course recommendations. I built an automated data pipeline using Firecrawl to scrape course syllabi and reviews, processing multi-dimensional workload metrics through parallel LLM chains before storing the extracted insights in Supabase. Furthermore, I implemented an agentic workflow with LangGraph, combining an LLM router with a tool-calling RAG agent that delivers schedule-grounded workload evaluations and interactive course suggestions. This solution streamlines the course registration research process, enabling students to make data-driven scheduling decisions and effectively optimize their academic workload."
