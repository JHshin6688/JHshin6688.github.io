- Built a Chrome extension enabling blind and low-vision users to interpret web content through AI-generated audio summaries, improving web accessibility for click-to-listen navigation
- Implemented the web content summarization pipeline using LangChain and Mistral AI, converting raw page content into concise, context-aware summaries for text-to-speech playback
- Collaborated in a team of four and awarded Best AI Project with Databricks Open Source at HackTX 2024
