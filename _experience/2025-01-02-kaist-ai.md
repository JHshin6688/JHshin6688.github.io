summary: "As an undergraduate researcher at <a href='https://sites.google.com/view/kaistdata/home?authuser=0'>DMLab</a>, I worked on improving recipe recommendation by making better use of the rich, multimodal information behind each recipe and user review. Existing approaches often left user review data underused, limiting how well a model could understand user's preferences. I built a data pipeline using LLaMA and LLaVA to convert multimodal recipe data and user reviews into informative textual summaries, then developed a framework that learns user and recipe embeddings through graph-based message propagation and cross-view contrastive learning. This approach improved Recall by roughly 10% over existing baselines."
